# Интернет-магазин «Web-Larёk»

«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component

Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`

#### Класс Api

Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter

Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` - хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

#### Модели данных

##### Класс Product

**Назначение и зона ответственности:**  
Модель данных для работы с каталогом товаров. Класс отвечает за хранение списка всех товаров каталога и выбранного товара. Предоставляет методы для получения, установки и поиска товаров в каталоге.

**Конструктор:**  
`constructor()` - конструктор не принимает параметров.

**Поля класса:**  
`private selected: IProduct | null` - хранит выбранный товар. Отвечает за хранение текущего выбранного товара из каталога. Может быть null, если товар не выбран.  
`private products: IProduct[]` - хранит массив всех товаров каталога. Отвечает за хранение полного списка товаров, доступных в каталоге.

**Методы класса:**  
`getProducts(): IProduct[]` - возвращает массив всех товаров каталога. Не принимает параметров.  
`setProducts(products: IProduct[]): void` - устанавливает массив товаров в каталог. Принимает параметр `products` типа `IProduct[]`. Не возвращает значения.  
`getSelected(): IProduct | null` - возвращает выбранный товар или null, если товар не выбран. Не принимает параметров.  
`setSelected(product: IProduct): void` - устанавливает выбранный товар. Принимает параметр `product` типа `IProduct`. Не возвращает значения.  
`getProductById(id: string): IProduct | undefined` - находит товар по его идентификатору и возвращает его, или undefined, если товар не найден. Принимает параметр `id` типа `string`.

##### Класс Cart

**Назначение и зона ответственности:**  
Модель данных для работы с корзиной покупок. Класс отвечает за хранение товаров, добавленных в корзину, управление содержимым корзины (добавление, удаление, очистка) и расчет общей стоимости товаров.

**Конструктор:**  
`constructor()` - конструктор не принимает параметров.

**Поля класса:**  
`private items: IProduct[]` - хранит массив товаров в корзине. Отвечает за хранение всех товаров, добавленных пользователем в корзину для покупки.

**Методы класса:**  
`getItems(): IProduct[]` - возвращает массив всех товаров в корзине. Не принимает параметров.  
`addItem(product: IProduct): void` - добавляет товар в корзину, если его там еще нет. Принимает параметр `product` типа `IProduct`. Не возвращает значения.  
`removeItem(itemId: string): void` - удаляет товар из корзины по его идентификатору. Принимает параметр `itemId` типа `string`. Не возвращает значения.  
`clear(): void` - очищает корзину, удаляя все товары. Не принимает параметров. Не возвращает значения.  
`getCount(): number` - возвращает количество товаров в корзине. Не принимает параметров.  
`getTotal(): number` - возвращает общую стоимость всех товаров в корзине. Не принимает параметров.  
`hasItem(productId: string): boolean` - проверяет, есть ли товар с указанным идентификатором в корзине. Принимает параметр `productId` типа `string`.

##### Класс Customer

**Назначение и зона ответственности:**  
Модель данных для работы с информацией о покупателе. Класс отвечает за хранение данных покупателя (способ оплаты, адрес доставки, контактные данные), управление этими данными и валидацию корректности заполнения полей.

**Конструктор:**  
`constructor()` - конструктор не принимает параметров.

**Поля класса:**  
`private _payment: TPayment | null` - хранит способ оплаты. Отвечает за хранение выбранного способа оплаты заказа (может быть 'card' или 'cash'). Может быть null, если способ оплаты не выбран.  
`private _address: string` - хранит адрес доставки. Отвечает за хранение адреса, на который необходимо доставить заказ.  
`private _email: string` - хранит электронную почту покупателя. Отвечает за хранение email-адреса для связи с покупателем.  
`private _phone: string` - хранит номер телефона покупателя. Отвечает за хранение телефонного номера для связи с покупателем.

**Методы класса:**  
`setCustomerInfo(data: ICustomer): void` - устанавливает всю информацию о покупателе из объекта. Принимает параметр `data` типа `ICustomer`. Не возвращает значения.  
`getCustomerInfo(): ICustomer` - возвращает объект с информацией о покупателе. Не принимает параметров.  
`clearCustomerInfo(): void` - очищает всю информацию о покупателе, сбрасывая все поля в начальное состояние. Не принимает параметров. Не возвращает значений.  
`validateCustomerInfo(): Record<string, string>` - проверяет корректность данных покупателя и возвращает объект с ошибками валидации (пустой объект, если ошибок нет). Не принимает параметров.

**Сеттеры:**  
`set payment(value: TPayment): void` - устанавливает способ оплаты. Принимает параметр `value` типа `TPayment`. Не возвращает значений.  
`set address(value: string): void` - устанавливает адрес доставки. Принимает параметр `value` типа `string`. Не возвращает значений.  
`set email(value: string): void` - устанавливает электронную почту. Принимает параметр `value` типа `string`. Не возвращает значений.  
`set phone(value: string): void` - устанавливает номер телефона. Принимает параметр `value` типа `string`. Не возвращает значений.

## 1. Класс Page

**Назначение:** Управляет главной страницей сайта - отображает счетчик корзины и каталог товаров в галерее.

**Конструктор:**
- Принимает: `container: HTMLElement`, `events: IEvents`
- Находит и сохраняет элементы:
  - `_basketButton: HTMLButtonElement` - кнопка корзины (.header__basket)
  - `_counter: HTMLElement` - счетчик товаров (.header__basket-counter)
  - `_gallery: HTMLElement` - контейнер галереи (.gallery)
- Устанавливает слушатели:
  - Клик на кнопку корзины → генерирует событие `basket:open`

**Поля класса:**
- `_basketButton: HTMLButtonElement` - кнопка открытия корзины
- `_counter: HTMLElement` - элемент со счетчиком
- `_gallery: HTMLElement` - контейнер для карточек товаров

**Методы/Сеттеры:**
- `set counter(value: number)` - обновляет число в счетчике корзины
- `set catalog(items: HTMLElement[])` - заменяет содержимое галереи массивом карточек
- `set locked(value: boolean)` - блокирует/разблокирует прокрутку страницы (при открытии модалки)

**События, которые генерирует:**
- `basket:open` - при клике на кнопку корзины

**Объяснение:** Page - это класс, который управляет всей главной страницей. Он отвечает за:
1. Отображение счетчика товаров в корзине в шапке
2. Отображение галереи товаров (вставка карточек)
3. Блокировку прокрутки когда открыто модальное окно

## 2. Класс Card (базовый, абстрактный)

**Назначение:** Базовый класс для всех типов карточек товаров. Содержит общий функционал, который используется во всех карточках.

**Конструктор:**
- Принимает: `container: HTMLElement`, `events: IEvents`

**Поля класса:**
- `protected _id: string` - ID товара (для передачи в событиях)
- `protected _title: HTMLElement` - элемент названия товара
- `protected _price: HTMLElement` - элемент цены
- `protected events: IEvents` - брокер событий

**Методы/Сеттеры:**
- `set id(value: string)` - сохраняет ID товара
- `set title(value: string)` - устанавливает название товара в DOM
- `set price(value: number | null)` - устанавливает цену (если null - показывает "Бесценно")

**Объяснение:** Это абстрактный родительский класс. От него наследуются CardCatalog, CardPreview, CardBasket. Он содержит то, что общее для всех карточек: id, title, price.

## 3. Класс CardCatalog extends Card

**Назначение:** Отображает компактную карточку товара в каталоге (галерее) на главной странице.

**Наследуется от:** Card

**Конструктор:**
- Принимает: `container: HTMLElement`, `events: IEvents`
- Находит и сохраняет дополнительные элементы:
  - `_category: HTMLElement` - элемент категории (.card__category)
  - `_image: HTMLImageElement` - изображение (.card__image)
  - `_button: HTMLButtonElement` - кнопка "Купить" (.card__button)
- Устанавливает слушатели:
  - Клик на карточку (не на кнопку) → `card:select`
  - Клик на кнопку "Купить" → `card:add`

**Поля класса:**
- Наследует от Card: `_id`, `_title`, `_price`
- `_category: HTMLElement` - элемент категории
- `_image: HTMLImageElement` - элемент изображения
- `_button: HTMLButtonElement` - кнопка действия

**Методы/Сеттеры:**
- Наследует от Card: `set id`, `set title`, `set price`
- `set category(value: string)` - устанавливает категорию и применяет CSS класс из `categoryMap` (из constants.ts)
- `set image(value: string)` - устанавливает src изображения
- `disableButton(state: boolean)` - блокирует кнопку (для бесценных товаров или уже добавленных)

**События, которые генерирует:**
- `card:select` - при клике на карточку, передает `{ id: string }`
- `card:add` - при клике на кнопку, передает `{ id: string }`

**Объяснение:** Это карточка, которая показывается в галерее. Когда кликаешь на нее - открывается детальный просмотр. Когда кликаешь "Купить" - товар добавляется в корзину. Категория товара отображается с цветом (софт-скил = зеленый, хард-скил = желтый и т.д.).

## 6. Класс Basket

**Назначение:** Отображает содержимое корзины в модальном окне - список товаров, общую сумму и кнопку оформления заказа.

**Конструктор:**
- Принимает: `container: HTMLElement`, `events: IEvents`
- Находит и сохраняет элементы:
  - `_list: HTMLElement` - контейнер списка (.basket__list)
  - `_total: HTMLElement` - элемент с суммой (.basket__price)
  - `_button: HTMLButtonElement` - кнопка "Оформить" (.basket__button)
- Устанавливает слушатели:
  - Клик на кнопку "Оформить" → `basket:order`

**Поля класса:**
- `_list: HTMLElement` - контейнер для списка товаров
- `_total: HTMLElement` - элемент отображения суммы
- `_button: HTMLButtonElement` - кнопка оформления заказа

**Методы/Сеттеры:**
- `set items(items: HTMLElement[])` - заменяет содержимое списка массивом карточек CardBasket
- `set total(value: number)` - обновляет отображение общей суммы ("X синапсов")
- `disableButton(state: boolean)` - блокирует/разблокирует кнопку "Оформить" (блокируется если корзина пустая)

**События, которые генерирует:**
- `basket:order` - при клике на кнопку "Оформить"

**Объяснение:** Корзина получает готовые HTML элементы карточек (CardBasket) и просто вставляет их в список. Показывает общую сумму. Если корзина пустая - кнопка "Оформить" заблокирована.

## 7. Класс Form (базовый, абстрактный)

**Назначение:** Базовый класс для всех форм. Содержит общую логику валидации, отображения ошибок и управления кнопкой отправки.

**Конструктор:**
- Принимает: `container: HTMLFormElement`, `events: IEvents`
- Находит и сохраняет элементы:
  - `_submit: HTMLButtonElement` - кнопка отправки
  - `_errors: HTMLElement` - элемент для ошибок (.form__errors)
- Устанавливает слушатели:
  - Событие `input` на форме - генерирует событие с данными поля
  - Событие `submit` на форме - генерирует событие отправки

**Поля класса:**
- `protected _submit: HTMLButtonElement` - кнопка отправки
- `protected _errors: HTMLElement` - элемент для отображения ошибок

**Методы/Сеттеры:**
- `set valid(value: boolean)` - включает/выключает кнопку submit в зависимости от валидности формы
- `set errors(value: string)` - отображает текст ошибки валидации
- `render(data: Partial<T> & { valid: boolean; errors: string })` - отрисовывает форму с данными и состоянием

**События, которые генерирует:**
- `{formName}:input` - при изменении любого поля, передает `{ field: string, value: string }`
- `{formName}:submit` - при отправке формы

**Объяснение:** Это родительский класс для форм. Он автоматически слушает изменения полей и отправку формы, генерирует события. Управляет кнопкой submit (блокирует если форма невалидна). От него наследуются OrderForm и ContactsForm.

## 8. Класс OrderForm extends Form

**Назначение:** Форма выбора способа оплаты и ввода адреса доставки (первый шаг оформления заказа).

**Поля класса:**
- Наследует от Form: `_submit`, `_errors`
- `_cardButton: HTMLButtonElement` - кнопка оплаты картой
- `_cashButton: HTMLButtonElement` - кнопка оплаты наличными

- `order:input` - при изменении полей (наследует от Form)
- `order:submit` - при отправке формы (наследует от Form)

**Объяснение:** Это первая форма оформления заказа. Пользователь выбирает как платить (онлайн или при получении) и вводит адрес. Кнопка submit становится активной только когда выбрана оплата И введен адрес.

## 10. Класс Modal

**Назначение:** Управляет модальным окном - открытие, закрытие, вставка контента. Универсальный компонент, может отображать любой контент.

**Конструктор:**
- Принимает: `container: HTMLElement`, `events: IEvents`
- Находит и сохраняет элементы:
  - `_closeButton: HTMLButtonElement` - кнопка закрытия (.modal__close)
  - `_content: HTMLElement` - контейнер для контента (.modal__content)
- Устанавливает слушатели:
  - Клик на кнопку закрытия → `modal:close`
  - Клик на overlay (затемненная область) → `modal:close`
  - Нажатие клавиши Escape → `modal:close`

**Поля класса:**
- `_closeButton: HTMLButtonElement` - кнопка закрытия
- `_content: HTMLElement` - контейнер для содержимого

**Методы:**
- `set content(value: HTMLElement)` - вставляет переданный HTML элемент в модальное окно
- `open()` - открывает модальное окно (добавляет класс `modal_active`)
- `close()` - закрывает модальное окно (удаляет класс `modal_active`)

**События, которые генерирует:**
- `modal:open` - при открытии модального окна
- `modal:close` - при закрытии модального окна

**Объяснение:** Модальное окно - это универсальный контейнер. В него можно вставить любой контент: карточку товара, корзину, форму, экран успеха. Закрывается по клику на крестик, на затемненную область или по Escape.

## ВАЖНЫЕ ПРИНЦИПЫ VIEW КЛАССОВ

### 1. View НЕ хранит данные
- Все данные в моделях (Product, Cart, Customer)
- View только отображает то, что ему передали

### 2. View НЕ содержит логику
- View не решает что отображать
- View не вызывает методы моделей напрямую
- Вся логика в Презентере (main.ts)

### 3. View генерирует события
- При любом действии п��льзователя → событие
- Презентер обрабатывает события и решает что делать

### 4. View находит элементы в конструкторе
- Все DOM элементы ищутся один раз при создании
- Сохраняются в поля класса
- Слушатели устанавливаются один раз в конструкторе

### 5. Метод render()
- Вызывается без аргументов - возвращает контейнер
- Вызывается с данными - обновляет отображение через сеттеры
